# Decision on additional meta-analysis

## Decision

A review-level meta-meta-analysis is prohibited. An optional de novo diagnostic-accuracy module is included, but disabled until verified primary-study 2×2 data are supplied.

## Why this is the best choice

The 155 quantitative estimates are not exchangeable observations. Reviews share publications and cohorts, use different thresholds, reference standards, follow-up windows, outcome definitions, and effect measures. Pooling them would create pseudo-replication and a clinically uninterpretable average.

Tap test, lumbar infusion/Rout, and extended lumbar drainage remain plausible targets for a separate updated diagnostic-accuracy component. That component would add value only if it reconstructs independent primary cohorts and compatible 2×2 tables. The present workbooks do not contain that information at the level required for a valid bivariate model.

## Current expected result

With the supplied template still empty, the code should conclude:

`NOT_READY_NO_PRIMARY_2X2_DATA`

This is intentional. It documents that the umbrella review is analysis-ready while a new primary-study meta-analysis is a separate expansion requiring additional searching, screening, extraction, and QUADAS-2 appraisal.
