# GitHub and Zenodo release procedure

## 1. Create the repository

Create a new public GitHub repository named `inph-shunt-ruleout-umbrella`. Upload the **contents** of this directory so that `README.md` is at the repository root. Do not upload an outer submission-package directory.

Recommended initial commit:

```text
Public reproducibility release for JNNP submission
```

Do not manufacture earlier commits or backdate the repository.

## 2. Run the release gate from a clean clone

```bash
git clone <repository-url>
cd inph-shunt-ruleout-umbrella
Rscript install_packages.R
Rscript run_all.R
Rscript scripts/validate_outputs.R
Rscript scripts/capture_environment.R
python scripts/static_release_check.py --release
```

Commit the newly generated `renv.lock`, `environment/session_info.txt`, and `environment/package_versions.csv` only after the clean run and validation pass.

## 3. Create the tagged GitHub release

Create tag:

```text
v1.2.3-journal-release
```

Attach the repository-generated ZIP or rely on the source archive generated by GitHub. The ZIP sent to JNNP must contain the same scientific files as this tagged release.

## 4. Archive with Zenodo

Enable the GitHub repository in Zenodo before publishing the GitHub release. After Zenodo archives the tagged release, record the **version-specific DOI**.

## 5. Update the manuscript

Replace `[DOI]` in the Data Availability Statement with the version-specific Zenodo DOI. Add the GitHub repository URL only after the repository is public and stable.

Recommended wording:

> Review-level analytic data, dated methodological materials, the statistical analysis plan and the R code required to reproduce the reported analyses are publicly available in the accompanying Zenodo archive (version 1.2.3; DOI: [DOI]) and GitHub repository. The same frozen reproducibility materials accompany this submission as online supplementary material. Full-text source publications are not redistributed and remain subject to their respective copyright holders.
